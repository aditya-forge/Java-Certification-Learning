# Module 1 - Introduction to the Course

A short module with no programming assignments. It covers what the course is about, how it is organised, and some advice on learning to program and asking for help. I used it mainly to get my setup working before the actual Java content starts in Module 2.

## What this module covers

- Overview of the course and where it fits in the Java specialization
- How to approach learning programming
- How to ask good questions on forums
- Resources for the rest of the course

## What I did

- Installed a JDK and BlueJ
- Compiled and ran a first program, from BlueJ and from the terminal
- Wrote down a few study habits I want to stick to (see `notes/`)
